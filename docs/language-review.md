# Native-speaker safety review

Review one English source alert and its output in Spanish, Arabic, Dari, or
Tagalog. Reviewers should be fluent adult speakers; professional emergency
interpreters are preferred but not required for this formative check.

For each of seven segments, mark:

| Check | Pass / fail |
|---|---|
| Every instruction has the same force and urgency | |
| Negation is preserved | |
| Places, roads, times, quantities and phone numbers are exact | |
| No new instruction or promise appears | |
| Wording is understandable without government vocabulary | |
| A withheld segment clearly shows the authoritative English | |

Record the language, reviewer qualification, date, segment ID, and a short
correction. Do not collect the reviewer’s personal disaster history. Two
independent reviewers per language is the production target; one per language
is acceptable only as clearly labelled hackathon evidence.
