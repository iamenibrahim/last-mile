# Five-person usability study

This is the smallest useful pre-demo study. It is not representative research;
report it as formative usability evidence.

## Participants

Recruit five adults who did not build the project. Ideally include one person
who uses assistive technology, one multilingual participant, and one person who
has previously applied for government assistance. Do not collect immigration,
medical, financial, or disaster-survivor details.

## Scenario

> A storm damaged your home. You are safe tonight, but you need temporary
> housing and lost your identification. Starting from the home page, find your
> next action and explain how you would continue later from another device.

## Measures

For each participant record only:

| Field | Value |
|---|---|
| Completed without help | yes / no |
| Time to first relevant action | seconds |
| Correctly identified that eligibility is not guaranteed | yes / no |
| Found the official source | yes / no |
| Found the continuity code | yes / no |
| Understood a withheld translation | yes / no / not shown |
| Confidence, 1–5 | number |
| One confusing phrase | anonymous text |

Ask afterward: “What would you do next?” and “What information did you think
the site kept about you?” Do not coach until the task ends.

## Reporting

Report counts, median completion time, and the top three observed problems. Do
not call five participants statistically representative. Fix severe confusion,
but preserve the study sheet as evidence rather than rerunning until everyone
passes.
