DATA MINIMIZATION

We ask for less on purpose.

Your location and broad situation are enough to screen for programs. The navigator does not request names, Social Security numbers, immigration status, bank details, or document uploads.

  • The full screening is not logged.
  • A minimal packet is retained for 24 hours only so the anonymous recovery code can resume it.
  • Offline device storage is opt-in and can be removed from the results screen.
  • Do not save a plan on a shared device.
  • Official agencies may ask for more only when you choose to apply.
